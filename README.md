## 1. Mathematical Logic & Conditional Evaluation

At its core, programming relies on manipulating data structures and steering execution pathways based on specific logical conditions.

### 📊 Marks & Grading System
This implementation demonstrates real-world application score processing using complex conditional routing, custom assignment operations, and value mapping trees.

* **Shorthand Assignment (`+=`):** Efficiently aggregates a baseline integer (`marks = 70`) by directly adding an incoming modifier payload (`bonus = 6`) without needing re-assignment.
* **Ternary Operation Evaluation:** Executes a highly optimized, single-line condition check (`marks >= 50 ? "PASS" : "FAIL"`) to determine passing status dynamically.
* **Sequential If-Else Chain:** Evaluates numeric bounds sequentially. By capturing upper limits first (`>= 90`), it avoids unneeded checks, cleanly filtering remaining boundaries down to a fallback failure state (`Grade F`).
* **Optimized Switch Statement Mapping:** Directs execution flow by matching the strict string value of the calculated `grade`. Using dedicated `case` gates and explicit `break` terminations prevents execution bleed (fall-through), mapping results cleanly to specialized string remarks.

## 2. Arithmetic Routing & Safe Operations

Robust code blocks must anticipate unexpected data inputs and enforce security rules before attempting system-critical tasks like mathematical execution.

### 🧮 Simple Calculator Prototype
This module establishes a blueprint for multi-operational mathematical evaluations while integrating structural guardrails.

* **Multi-Operator Routing:** Leverages logical equivalence evaluations (`===`) to identify the target arithmetic operator (`+`, `-`, `*`, `/`) and matches it against incoming numerical variables (`n1`, `n2`).
* **Division-by-Zero Exception Prevention:** Features a critical inner validation check (`if (n2 === 0)`). By intercepts calculations before executing a division operation, it safely blocks mathematically illegal executions—printing a descriptive system log rather than returning an unmanageable `Infinity` value or crashing runtime execution.
